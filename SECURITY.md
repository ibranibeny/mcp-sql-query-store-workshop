# Security Policy

## Supported scope

Security fixes are supported for the current default branch of this workshop repository. The lab automation and workload are intended only for an isolated, disposable workshop environment.

Do not run the workload scripts against production.

## Private reporting

Report suspected vulnerabilities privately through the repository's GitHub Security Advisories page. Do not open a public issue for a suspected vulnerability. Include reproduction details and impact, but never put credentials, connection strings, private keys, certificates, or other secrets in an issue or report.

Password-bearing examples may use the literal `WORKSHOP-PLACEHOLDER` marker. It is documentation only and must never be replaced with a real secret in a tracked file.
